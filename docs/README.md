# Documents

Read in this order.

| document | what it is |
|---|---|
| `../README.md` | overview of the library, headline statements, build and axiom check |
| `SPEC.md` | the specification: machine, arithmetization, J-8 to J-9 AL theorems, trace uniqueness, succinct layer, end-to-end theorems, executables, scope |
| `LIMITS.md` | trusted base and stated gaps of both packages |
| `REPRODUCE.md` | how to build, check axioms, and re-run the demo, the fixtures, the free front end and the benchmark |
| `THEOREMS.md` | every headline declaration with its location, statement head and recorded `#print axioms` line (generated by `gen/theorem_index.py` from `gen/headlines.txt`; `theorems-all.tsv` lists every recorded line; `theorems-unrecorded.tsv` lists the declarations `SPEC.md` cites that have no recorded line) |
| `GLOSSARY.md` | release labels and opaque name prefixes mapped to descriptive names |
| `../nockvm-e2e/README.md` | the end-to-end package: headlines, fixtures, running an arbitrary program, ArkLib attribution, source layout |
| `../nockvm-e2e/CERTIFIED.md` | design of the certified verifier `nockvm-e2e-verify-cert` |
| `../nockvm-e2e/vendor/arklib-fs/README.md` | provenance of the vendored ArkLib modules |

`j8/SPEC.md` maps the section numbers that code comments cite to sections of `SPEC.md`.
